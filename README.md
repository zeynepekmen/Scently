
# SCENTLY

## Proje Hakkında
Scently, kullanıcıların farklı parfümleri karşılaştırmasına yardımcı olan bir web sitesidir.

## Projenin Amacı
Kullanıcıların parfümleri koku uyumu, kullanım uygunluğu ve fiyat avantajı kriterlerine göre karşılaştırabilmesini sağlamak.

## Özellikler
- 12 farklı parfümü keşfetme
- İki parfümü karşılaştırma
- Karşılaştırma kriterlerine yüzde belirleme
- Parfümlerin puanlarını görüntüleme
- Fiyat / ml hesaplama

## Kullanılan Teknolojiler
- HTML
- CSS
- JavaScript

## Geliştirici
Scently, eğitim amacıyla geliştirilmiş bir web projesidir.
